# Топология электрических цепей и структура соединений между элементами

Ты подошёл к области, которая называется **теория электрических цепей, теория графов и топология интегральных схем**.

Математический аппарат для строгого описания соединений уже существует. Однако единственного универсального описания, которое одинаково удобно отражало бы геометрию, проводимость, движение зарядов, время, энергопотребление и вычислительные процессы, нет.

И здесь есть пространство для исследований.

## 1. Фундаментальные отношения между элементами

Если временно забыть о назначении транзисторов, дешифраторов и усилителей, можно изучать исключительно отношения между физическими элементами.

| Отношение | Содержание |
|---|---|
| Контакт | Непосредственное физическое соприкосновение |
| Изоляция | Отсутствие непосредственного проводящего контакта |
| Последовательность | Соединение элементов друг за другом без разветвления между ними |
| Параллельность | Соединение элементов через два общих электрических узла |
| Разветвление | Соединение нескольких проводящих путей в одном узле |
| Пересечение | Геометрическое пересечение, необязательно электрический контакт |
| Замкнутость | Наличие замкнутого пути |
| Электрическая связанность | Возможность прохождения тока между участками |
| Полевая связанность | Взаимодействие посредством электрического поля |
| Вложенность | Объединение структур меньшего масштаба в структуры большего масштаба |

## 2. Как это описывают математически

В электронике широко используются графы и гиперграфы. Например, гиперграф позволяет описывать одну электрическую сеть, соединяющую сразу множество контактов. ([Источник](https://vlsicad.ucsd.edu/Publications/Journals/j37.pdf))

Но я бы предложил тебе изучать электрические цепи через **четыре одновременно существующие структуры**.

| Структура | Что изучаем |
|---|---|
| Геометрическая | Координаты, расстояния, толщины, пространственное расположение |
| Топологическая | Что с чем соединено |
| Электрофизическая | Напряжение, сопротивление, проводимость, ёмкость |
| Динамическая | Как электрические состояния изменяются во времени |

## 3. Необычный взгляд на транзистор

Представь, что вся видеокарта — это огромная трёхмерная сеть потенциально проводящих путей.

Физическая структура этой сети практически неподвижна. Однако её **электрическая связность непрерывно изменяется**.

Транзисторы открывают и закрывают проводящие пути, не перемещаясь в пространстве.

Математически можно представить это как:

$$
G(t)=(V,E,w(t))
$$

где:

- $V$ — электрические узлы;
- $E$ — потенциальные соединения;
- $w(t)$ — изменяющиеся во времени параметры проводимости.

Получается, что выполнение программы можно рассматривать как последовательность изменений состояния взвешенного графа электрических соединений.

Это упрощённая модель: для полноценного описания необходимо дополнительно учитывать ёмкости, напряжения, нелинейность элементов и другие физические свойства.

## 5. Где начинается исследовательский интерес

Можно ли математически описать архитектуру вычислительной системы так, чтобы из структуры её электрических соединений определять:

- потенциальный предел параллельности;
- минимально возможное энергопотребление;
- минимальную задержку передачи информации;
- избыточность переключений;
- оптимальное пространственное расположение вычислений и памяти?

Отдельные части этих задач уже активно исследуются. Например, исследователи DRAM обнаружили возможности повышения параллельности благодаря анализу общих и независимых соединений подмассивов памяти. ([Источник: SALP](https://pdl.cmu.edu/PDL-FTP/NVM/ISCA39_SALP_abs.shtml))

**Особенно интересная для нас мысль:**

Физическая структура вычислительной системы постоянна, электрическая связность изменчива, а вычисления представляют собой управляемую последовательность этих изменений.

Это не новое математическое открытие, но очень продуктивная отправная точка для изучения вычислительной архитектуры и самостоятельного поиска закономерностей.
