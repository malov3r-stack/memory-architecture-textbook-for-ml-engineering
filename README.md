# Архитектура электрических связей в DRAM: от матриц до кристаллов памяти

Рассмотрим последовательную иерархию физических и электрических соединений\:

1. Матрицы памяти внутри подмассива (Subarray).
2. Подмассивы внутри банка (Bank).
3. Банки внутри кристалла (Die).
4. Кристаллы между собой внутри модуля памяти (DIMM).

Для каждого уровня отдельно рассмотрим\:

- Физическое расположение элементов.
- Структуру электрических соединений.
- Направление прохождения сигналов.
- Последовательные и параллельные отношения.
- Положительную и отрицательную полярность электрических цепей.

Важно: речь идёт о типичной архитектуре DRAM. Конкретная топология зависит от поколения памяти, производителя и реализации кристалла.

---

# 1\. Матрицы памяти внутри подмассива (Subarray)

## 1.1. Физическая структура

Матрица памяти представляет собой двумерную сетку, состоящую из множества ячеек.

Каждая ячейка располагается на пересечении двух типов проводников\:

- Word Line (WL) — горизонтальная линия выбора строки.
- Bit Line (BL) — вертикальная линия передачи данных.

Каждая ячейка DRAM обычно содержит\:

- Один транзистор доступа (Access Transistor).
- Один конденсатор (Capacitor).

Транзистор соединяет конденсатор ячейки с битовой линией при активации соответствующей линии выбора строки.

Таким образом, физическая структура матрицы формируется пересекающимися горизонтальными и вертикальными проводниками.

## 1.2. Горизонтальные связи — Word Lines

Word Line проходит вдоль горизонтального направления матрицы.

Одна линия WL связана с управляющими транзисторами ячеек, расположенных в соответствующей строке.

Если активируется конкретная WL, транзисторы всех ячеек этой строки открываются одновременно.

В результате конденсаторы выбранной строки получают электрическую связь со своими соответствующими Bit Lines.

Особенности\:

- Одна WL управляет целым рядом ячеек.
- WL подключена к множеству транзисторов.
- WL является общей управляющей линией для выбранной строки.
- Разные WL соответствуют разным строкам матрицы.

**Отношение\:** одна линия управления имеет разветвлённые соединения с множеством транзисторов. Это не последовательное соединение ячеек: они подключены к общей управляющей линии.

## 1.3. Вертикальные связи — Bit Lines

Bit Line проходит вдоль вертикального направления матрицы.

Одна BL связана с транзисторами ячеек, расположенных в соответствующем столбце.

Когда активируется WL, транзисторы выбранной строки открываются, и состояние конденсаторов передаётся на соответствующие BL.

Особенности\:

- Одна BL обслуживает несколько ячеек одного столбца.
- Одновременно открытая строка подключает к BL одну ячейку соответствующего столбца.
- BL передаёт сигнал к усилителю считывания.
- Каждая BL имеет электрическую нагрузку, образованную проводником и подключёнными элементами.

В отличие от WL, которая управляет доступом, BL непосредственно участвует в передаче данных.

## 1.4. Отношение между WL и BL

WL и BL расположены перпендикулярно.

Их пересечение образует координатную позицию ячейки.

При этом сами линии не образуют электрического соединения непосредственно в точке геометрического пересечения. Электрическая связь между ними осуществляется через транзистор доступа и конденсатор ячейки.

Для выбора конкретной ячейки необходимо сочетание\:

- Активированной строки.
- Выбранного столбца.

Таким образом, адресация строится на двух независимых координатных направлениях.

## 1.5. Усилители считывания (Sense Amplifiers)

На границе матрицы располагаются усилители считывания.

Они подключаются к битовым линиям и выполняют несколько функций\:

- Определяют небольшое изменение напряжения на BL.
- Усиливают разницу напряжений.
- Восстанавливают полноценный логический уровень.
- Возвращают заряд в конденсатор выбранной ячейки после чтения.

В распространённой архитектуре используются дифференциальные пары BL и BLB.

BLB — инверсная битовая линия, работающая совместно с BL.

Таким образом, считывание происходит через сравнение электрических состояний двух линий.

# 2\. Подмассивы внутри банка памяти (Bank)

## 2.1. Физическая структура

Банк памяти представляет собой более крупную организационную единицу, содержащую множество подмассивов.

Каждый подмассив включает\:

- Собственную матрицу ячеек.
- Систему WL.
- Систему BL.
- Усилители считывания.
- Локальные схемы управления.

Подмассивы физически размещаются отдельными областями на кристалле.

Между ними располагаются или вдоль них проходят дополнительные электрические структуры, обеспечивающие обмен данными и управляющими сигналами.

## 2.2. Локальные соединения внутри подмассива

Внутри каждого подмассива битовые линии соединяются с усилителями считывания.

Эти линии называются локальными битовыми линиями.

После считывания данные находятся в усилителях, которые фактически выполняют роль промежуточного буфера.

Важная особенность: усилители считывания не просто измеряют сигнал, но и удерживают восстановленное состояние данных открытой строки.

Поэтому после активации строки данные могут использоваться для нескольких операций обращения к столбцам без повторного открытия строки.

## 2.3. Связи между подмассивами

Подмассивы не соединяются между собой простым последовательным соединением всех битовых линий.

Вместо этого используются отдельные уровни передачи данных.

Типичная структура включает\:

1. Локальные битовые линии (Local Bit Lines).
2. Усилители считывания.
3. Глобальные битовые линии (Global Bit Lines).
4. Схемы выбора столбцов.
5. Общую схему ввода-вывода банка.

Глобальные линии обеспечивают передачу данных между локальными областями и общей периферией банка.

В зависимости от реализации глобальные линии могут объединять выходы нескольких локальных групп усилителей через переключающие транзисторы и мультиплексоры.

## 2.4. Направление передачи данных

При чтении\:

1. Активируется строка выбранного подмассива.
2. Сигналы ячеек поступают на локальные BL.
3. Усилители считывания усиливают и восстанавливают сигнал.
4. Выбранные данные передаются через глобальные линии.
5. Схема выбора столбца направляет данные в интерфейс банка.

При записи направление противоположное\:

1. Данные поступают от интерфейса банка.
2. Схемы выбора направляют их к соответствующим усилителям.
3. Усилители формируют требуемое электрическое состояние.
4. Через локальные BL данные записываются в выбранные ячейки.

## 2.5. Последовательные и параллельные отношения

Здесь необходимо различать два типа отношений.

**Параллельность размещения и работы\:**

- Подмассивы представляют собой отдельные физические области.
- В разных подмассивах могут выполняться некоторые операции одновременно.
- Для этого используются независимые локальные ресурсы.

**Последовательность передачи\:**

При чтении выбранного набора данных сигнал проходит через несколько функциональных ступеней\:

Локальная BL → усилитель считывания → глобальная BL → схема выбора столбца → интерфейс банка.

Это последовательность функциональных этапов передачи, а не обязательно последовательное электрическое соединение всех компонентов в одной цепи.

# 3\. Банки внутри кристалла памяти (Die)

## 3.1. Физическая структура

Кристалл DRAM содержит несколько банков памяти.

Каждый банк представляет собой самостоятельную область хранения данных с собственными\:

- Подмассивами.
- Матрицами ячеек.
- Локальными усилителями считывания.
- Схемами выбора строк и столбцов.
- Внутренними линиями передачи данных.

Помимо банков, на кристалле размещаются общие схемы управления и интерфейсные структуры.

К ним относятся\:

- Command Decoder.
- Address Logic.
- Timing Control.
- Data I/O.
- Схемы генерации и распределения внутренних напряжений.
- Схемы синхронизации.

Банки могут группироваться в Bank Groups.

Группировка банков позволяет организовать более гибкое управление обращениями к памяти.

## 3.2. Управляющие связи между банками

Банки получают команды от общей логики управления кристаллом.

Команды могут включать\:

- ACTIVATE — открыть строку.
- READ — прочитать данные.
- WRITE — записать данные.
- PRECHARGE — закрыть активную строку и подготовить банк к следующей операции.

Общая логика декодирует команду и определяет, к какому банку она относится.

Адресная информация направляется соответствующим схемам выбора строк и столбцов.

Таким образом, управляющие сигналы распространяются от общей логики к выбранным банкам.

## 3.3. Связи данных между банками

Каждый банк располагает собственным внутренним трактом передачи данных.

Однако на уровне кристалла данные должны поступать к общему интерфейсу ввода-вывода.

Для этого используются внутренние шины, переключатели и схемы мультиплексирования.

Их задача — направить данные выбранного банка к соответствующим выводам кристалла.

Важно: банки не соединяются друг с другом последовательно, чтобы передавать данные от одного банка к следующему.

Каждый банк имеет собственный путь к общей инфраструктуре передачи данных.

## 3.4. Параллельные отношения между банками

Банки могут работать независимо в определённых пределах.

Например\:

- Один банк выполняет активацию строки.
- Другой банк выполняет предварительный заряд.
- Третий банк обслуживает чтение.

Такая организация позволяет перекрывать некоторые операции во времени.

Однако независимость не абсолютная.

Банки могут использовать общие ресурсы\:

- Интерфейс данных.
- Внутренние шины.
- Схемы управления.
- Тактовую инфраструктуру.

Поэтому параллельная работа ограничивается пропускной способностью общих элементов и временными параметрами DRAM.

## 3.5. Последовательность передачи данных

При чтении\:

Банк → внутренняя схема передачи данных → мультиплексирование → Data I/O → выводы кристалла.

При записи\:

Выводы кристалла → Data I/O → внутренняя схема распределения → выбранный банк.

Это функциональная последовательность прохождения данных через уровни кристалла.

# 4\. Связи между кристаллами памяти

## 4.1. Физическая структура модуля DIMM

Модуль памяти представляет собой печатную плату с установленными на ней микросхемами DRAM.

На плате располагаются\:

- Кристаллы памяти в корпусах.
- Проводящие дорожки.
- Контактные площадки.
- Электрические цепи питания.
- Цепи передачи команд и адресов.
- Цепи передачи данных.

В зависимости от конструкции модуля также могут присутствовать дополнительные микросхемы, например регистры, буферы и PMIC.

Важное различие: кристалл (Die) и микросхема в корпусе (Package) — не всегда одно и то же. Один корпус может содержать несколько кристаллов.

## 4.2. Управляющие соединения между кристаллами

Контроллер памяти передаёт команды и адреса через соответствующие электрические линии.

В типичной организации DDR-модуля\:

- Линии команд и адресов могут быть общими для нескольких микросхем одного Rank.
- Выбор конкретной группы микросхем осуществляется сигналами Chip Select и соответствующей логикой.
- В зарегистрированных модулях RDIMM между контроллером и DRAM дополнительно находится регистр команд и адресов.

Таким образом, управляющие сигналы могут распространяться по общей разветвлённой инфраструктуре.

Это не означает, что все микросхемы одновременно выполняют одну операцию: выбор определяется командами и сигналами управления.

## 4.3. Соединения линий данных

Линии данных организуются отдельно от управляющих линий.

В обычном DDR-модуле ширина канала данных часто составляет 64 бита.

При этом отдельные микросхемы могут обслуживать разные части этой ширины.

Например, если используются восемь микросхем x8\:

- Каждая микросхема передаёт 8 бит.
- Восемь микросхем совместно формируют 64-битную ширину данных.
- Они работают согласованно в рамках одного Rank.

Это пример параллельного объединения разрядности.

Каждая микросхема передаёт собственную группу битов, а контроллер получает их как единое слово данных.

## 4.4. Последовательные и параллельные отношения

**Параллельное отношение\:**

Кристаллы в одном Rank могут одновременно передавать разные части одного 64-битного слова.

Их выходы подключены к разным линиям общей шины данных.

**Общая электрическая инфраструктура\:**

Несколько микросхем могут иметь общие управляющие линии.

Такие соединения представляют собой разветвлённые сети, а не последовательную передачу сигнала через каждую микросхему.

**Несколько Rank\:**

В модуле могут присутствовать несколько Rank.

Они используют общую инфраструктуру канала, но выбираются отдельно. Для разделения их работы используются сигналы выбора и соответствующие схемы управления.

# 5\. Положительная и отрицательная полярность электрических цепей

Теперь отдельно рассмотрим полярность.

Здесь важно различать\:

- Полярность питания.
- Уровни напряжения сигнала.
- Дифференциальную полярность пары проводников.

Это разные электрические характеристики.

## 5.1. Полярность питания

Электрические схемы DRAM получают питание от нескольких цепей напряжения.

У каждой цепи есть\:

- Положительная линия питания.
- Общий потенциал или соответствующая опорная линия.

Например, для DDR4 характерно использование VDD около 1,2 В, а для DDR5 — около 1,1 В для основной цепи DRAM.

Отдельно могут присутствовать напряжения для внутренних схем, периферии и терминаторов.

Положительная линия питания обеспечивает подачу энергии в электрические схемы.

Общая линия служит опорным потенциалом для формирования и измерения напряжений.

Это не означает, что данные передаются по положительному и отрицательному проводникам питания.

## 5.2. Дифференциальная полярность Bit Line

Внутри матрицы DRAM часто используется дифференциальная пара\:

- BL — Bit Line.
- BLB — Bit Line Bar.

Они подключаются к дифференциальному усилителю считывания.

Перед считыванием обе линии обычно предварительно устанавливаются примерно на половину напряжения питания матрицы.

Затем при подключении ячейки возникает небольшая разница между их напряжениями.

В зависимости от сохранённого состояния ячейки\:

| Линия | Состояние A | Состояние B |
|--------|--------|--------|
| BL | Немного выше | Немного ниже |
| BLB | Немного ниже | Немного выше |

Усилитель считывания определяет направление этой разности и усиливает её.

Таким образом, два логических состояния представлены противоположными направлениями дифференциального напряжения.

Важно: BLB не является постоянно отрицательной линией питания. Она не обязательно имеет отрицательное напряжение относительно земли.

Термины «положительная» и «отрицательная» здесь обозначают полярность разности напряжений между двумя проводниками.

## 5.3. Дифференциальные соединения на других уровнях

Дифференциальные пары встречаются не только внутри матрицы.

В DRAM могут использоваться дифференциальные линии\:

- В цепях тактового сигнала.
- В отдельных управляющих интерфейсах.
- В специализированных высокоскоростных интерфейсах.

Но нельзя считать, что все линии памяти имеют положительную и отрицательную пару.

Например, стандартная шина данных DDR использует отдельные линии DQ для передачи битов, а не дифференциальную пару BL/BLB для каждого бита на уровне внешнего интерфейса.

# 6\. Сводная классификация структурных отношений

Здесь собраны типы соединений, встречающиеся на каждом уровне.

| Уровень | Элементы | Структура связей | Отношение |
|--------|--------|--------|--------|
| Матрица | WL и BL | Перпендикулярная сетка | Пересечение |
| Ячейки | Транзисторы и конденсаторы | Подключение к WL и BL | Управляемое подключение |
| Подмассив | BL и усилители | Локальные линии | Разветвлённая сеть |
| Подмассивы | Локальные и глобальные линии | Через переключатели | Иерархическое объединение |
| Банк | Подмассивы | Общая периферия | Параллельное размещение, общее управление |
| Кристалл | Банки | Общая логика и интерфейс | Параллельная организация |
| Модуль | Кристаллы | Проводящие дорожки | Общие и индивидуальные линии |
| Rank | Микросхемы x8/x16 | Совместная шина данных | Параллельное объединение разрядности |
| DIMM | Несколько Rank | Общий канал | Независимый выбор |

# 7\. Основные направления электрических сигналов

Необходимо разделять три направления передачи.

| Тип сигнала | Основное направление |
|--------|--------|
| Адресные сигналы | Контроллер → кристалл → банк → декодеры |
| Управляющие сигналы | Контроллер → логика управления → выбранные структуры |
| Данные при чтении | Ячейка → BL → усилитель → глобальные линии → Data I/O → контроллер |
| Данные при записи | Контроллер → Data I/O → глобальные линии → усилитель → BL → ячейка |
| Питание | Источник питания → распределительная сеть кристалла → электрические схемы |

## 8\. Принципиальное различие последовательного и параллельного соединения

В архитектуре DRAM эти понятия нельзя применять ко всей иерархии целиком.

**Последовательность** характеризует цепочку функциональных этапов передачи сигнала. Например\:

Усилитель считывания → переключатель → глобальная линия → интерфейс данных.

**Параллельность** характеризует независимые электрические пути, которые могут работать одновременно.

Например\:

- Разные битовые линии матрицы.
- Разные локальные группы усилителей.
- Разные банки.
- Разные каналы памяти.
- Несколько микросхем, одновременно формирующих одно слово данных.

**Разветвление** характеризует ситуацию, когда один управляющий или питающий проводник обслуживает несколько потребителей.

**Объединение** характеризует ситуацию, когда несколько локальных путей сходятся к общей инфраструктуре через переключатели, мультиплексоры или другие схемы.

Именно эти четыре отношения — последовательность, параллельность, разветвление и объединение — позволяют описывать электрическую архитектуру DRAM без смешивания её с геометрическим расположением компонентов.
